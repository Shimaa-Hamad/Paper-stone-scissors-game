# Rock Paper Scissors Game 🎮

A console-based Rock-Paper-Scissors game built with C++.

The player competes against the computer in a number of rounds. After each round, the winner is displayed, and the game ends with a final result summary.

## 🔧 Features

- Choose how many rounds to play (1 to 10)
- Play against a randomly choosing computer
- Colored screen feedback:
  - 🟩 Green for player win
  - 🟥 Red for computer win
  - 🟨 Yellow for draw
- End of game result summary
- Option to replay the game

## 🚀 How to Run

1. **Clone or download** the project.

2. **Compile using g++**:
   ```bash
   g++ -o RockPaperScissors RockPaperScissors.cpp
